# @venue/web

React 19 + Vite frontend for the venue booking system (TanStack Router/Query/Form, shadcn/ui on Base UI, Tailwind CSS v4, i18next).

- `src/routes/` file-based routes; `src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin.
- `src/features/` venue board, booking flow and reservation pages.
- `src/locales/` English and Simplified Chinese strings.
- `src/lib/api.ts` typed client generated from the shared `@venue/contracts` contract.

Add shadcn/ui components from this directory, for example `bunx --bun shadcn@latest add dialog`.

See the [root README](../../README.md) for setup and development commands.
